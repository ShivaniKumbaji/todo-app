PROJECT OVERVIEW:
The To-Do Application allows users to:
Register and log in securely
Create, update, delete tasks
Set task priority and due dates
Mark tasks as completed
Manage tasks in a clean, user-friendly interface
This application demonstrates real-world CRUD operations, authentication, and MVC architecture using Flask.
